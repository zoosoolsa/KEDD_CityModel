# KEDD CityModel

위경도 범위만 정하면 **지형 + 건물 + 도로·다리 + 녹지·물**이 들어간 도시 클레이 모델을 Blender 파일(`.blend`)로 만들어 주는 앱입니다. Windows와 macOS에서 실행됩니다.

- 건물: 브이월드 **GIS건물통합정보**를 쓰고, 빠진 건물과 높이는 **OpenStreetMap**으로 보완합니다.
- 지형: **Copernicus DEM 30m**를 자동으로 내려받습니다.
- 도로·다리·녹지·물: **OpenStreetMap**(Geofabrik 한국 데이터)을 자동으로 내려받습니다.
- 렌더: 건물과 땅은 흰색이고 녹지·물·도로에만 색이 들어갑니다. AO(앰비언트 오클루전) 합성과 카메라 배치까지 설정된 상태로 나옵니다.

## 필요한 것

1. **Blender 3.3 이상** (4.x·5.x 동작, 자동 탐색).
2. **브이월드 인증키** (무료). 브이월드 → 오픈API → 인증키 발급에서 **서비스 URL을 `http://localhost:47380`** 으로 등록하고, 받은 키를 앱의 **[설정] → 브이월드 인증키**에 넣고 **[저장·확인]**. 키는 이 컴퓨터에만 저장되고(macOS: 홈 폴더의 개인 파일, Windows: 자격 증명 관리자) 저장소나 앱 파일에는 들어가지 않습니다.
3. **브이월드 GIS건물통합정보** 시도별 zip (앱이 받기를 도와줍니다, 아래).
4. 처음 실행할 때 인터넷 연결 (OSM 약 300MB, 지형 타일). 이후에는 캐시 사용.

## 사용법 (v2)

1. **프로젝트**를 고르거나 새 이름을 씁니다. 같은 프로젝트에는 카메라가 계속 쌓입니다.
2. **[브이월드 3D 지도 열기]** → 브라우저에 앱 내장 3D 지도가 열립니다. 장소를 검색하고 원하는 구도를 잡은 뒤 **[이 시점으로 생성]**.
3. 앱이 판단해서 확인 창을 띄웁니다.
   - 이미 만든 모델이 그 시점을 덮고 있으면 → **카메라만 추가** (수 초)
   - 모자란 구역이 있으면 → **없는 4km 타일만 새로 만들고** 기존 타일은 재사용한 뒤 다시 조립
4. 완료 후 Blender로 열어 **F12**. 카메라는 `Cameras` 컬렉션에 쌓이고, 마지막 것이 활성 카메라입니다.

웹 지도 URL(구글 어스·구글 지도·네이버·카카오)을 붙여 넣거나, 범위(경위도)로 만드는 방식도 그대로 쓸 수 있습니다.

### 카메라 히스토리

- 프로젝트 하나 = `.blend` 하나이고, 시점을 보낼 때마다 카메라와 **썸네일**이 쌓입니다.
- 앱의 **[카메라]** 탭에 썸네일 목록이 나오고, 두 번 클릭하면 그 카메라 뷰로 Blender 가 열립니다.
- Blender 에서는 3D 뷰 사이드바(**N**) → **KEDD** 탭: 썸네일을 누르면 활성 카메라·해상도·뷰가 바로 바뀝니다. 현재 뷰를 카메라로 추가, 썸네일 다시 만들기, 삭제, 이름 바꾸기(목록에서 더블클릭)도 됩니다. 저장하면 앱 쪽 목록에도 반영됩니다.
- 패널은 앱이 처음 생성할 때 Blender 애드온으로 설치합니다.
- Blender 에서 이미 열려 있으면 새 창을 열지 않고 그 창에서 카메라만 바꿉니다. 앱에서 카메라·모델을 추가하면 열린 Blender 가 파일을 자동으로 다시 불러옵니다(저장 안 한 변경이 있으면 안내만 함).

### 모델 재사용과 갱신

- 모델은 `작업폴더/tiles/` 에 4km 타일 단위로 저장되고, 프로젝트(`작업폴더/projects/이름/`)는 필요한 타일을 모아 조립합니다.
- 타일은 **새 정보가 있을 때만** 다시 만듭니다: 그 구역의 건물 zip이 더 새 날짜로 바뀌었을 때, OSM이 갱신됐을 때(기본 90일), 브이월드 API 높이 보완을 새로 켰을 때, 엔진이 바뀌었을 때.
- **지형 과장**을 바꾸면 모든 타일을 다시 만들어야 해서 확인 창에 경고가 나옵니다.

## 건물 데이터 폴더 (전국 관리)

**[건물 데이터]** 탭이 브이월드 공개 목록(로그인 불필요)을 읽어 시도별 상태를 보여 줍니다.

- **보유**(흐리게): 폴더에 있음. 더 새 버전이 나왔으면 `보유(구)`.
- **없음**: 폴더에 없음. 주황색 ★ 는 지금 범위에 필요한 시도입니다.
- **[선택 받기]**: 고른 '없음' 항목(아무것도 안 고르면 범위에 필요한 것)을 앱이 직접 건물 데이터 폴더로 받습니다. 브이월드 로그인이 필요하면 앱 안 로그인 창이 한 번 뜨고, 로그인하면 자동으로 닫힙니다(비밀번호는 앱이 보거나 저장하지 않고 로그인 상태만 보관). 브라우저 탭은 열지 않습니다. 받은 뒤 인덱스를 만들고 이전 버전은 정리합니다.
- 브라우저로 직접 받은 파일: 앱을 켤 때 다운로드 폴더에서 자동으로 가져옵니다(Safari 가 푼 폴더, `(1)` 이름 포함). macOS 가 다운로드 폴더 접근을 막으면 **[파일 직접 추가…]** 로 고르면 됩니다.
- **브이월드 API 사용**(인증키 필요):
  - **지적도 도로**: 연속지적도를 받아 '도로' 필지와 필지가 없는 공공 도로(필지 사이 빈 곳, 물 제외)를 도로 면으로 씁니다. GIS 건물과 같은 지적 기준이라 골목까지 건물과 맞습니다. 받지 못한 구역은 OSM 도로로 채웁니다.
  - **건물 높이**: 도로명주소건물(층수)로 GIS에 없는 건물·층수를 보완합니다.
  - 받은 데이터는 35일간 캐시합니다.

## 렌더 팁

- **GPU 렌더**: 환경 설정 → 시스템 → Cycles 렌더 장치에서 Metal(Mac) 또는 CUDA/OptiX(NVIDIA)를 켜세요.
- **AO 진하기**: Compositing 탭 → `AO 강도` Math 노드 값을 바꾸세요. 범위는 월드 속성 → 앰비언트 오클루전 → 거리에서 조정합니다.
- **색**: `Ground` 재질에서 녹지와 물(Mix 노드 두 개)을, `Road` 재질에서 도로를, `Clay_Building` 재질에서 건물 색을 바꿉니다.
- **현재 뷰로 렌더**: 보기 → 정렬 뷰 → 활성 카메라를 뷰에 정렬을 한 뒤 F12를 누르세요.

## 개발 / 빌드

```
pip install -r requirements.txt
python -m citymodel                        # GUI
python -m citymodel --config settings.json # GUI 없이 실행
```

배포판 빌드:

- 로컬: `pip install pyinstaller` → `pyinstaller packaging/citymodel.spec --noconfirm`
- GitHub: 태그를 푸시하면(`git tag v1.0.0 && git push --tags`) Actions가 Windows / macOS(Apple Silicon, Intel)용 zip을 만들어 Release에 올립니다.

### macOS 첫 실행

서명되지 않은 앱이라 처음에는 macOS가 실행을 막을 수 있습니다. **앱을 우클릭 → 열기**로 실행하거나, 시스템 설정 → 개인정보 보호 및 보안에서 "그래도 열기"를 누르세요.

## 알려진 한계

- 높이 정보가 없는 건물(원본·OSM 모두)은 기본 7m로 들어갑니다.
- 지형은 30m 해상도이고 산 정상부가 약간 낮아집니다(건물·수목 제거 필터 때문).
- 도로는 지형 삼각형에 정확히 얹은 면이라 지면과 높이가 항상 맞고, 다리·고가는 입체입니다. 인증키가 있으면 지적도 도로 필지, 없으면 OSM 도로(일부 골목 누락, 몇 m 어긋남 가능)를 씁니다.
- 터널은 표시하지 않습니다.
