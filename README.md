# KEDD CityModel

위경도 범위만 정하면 **지형 + 건물 + 도로·다리 + 녹지·물**이 들어간 도시 클레이 모델을 Blender 파일(`.blend`)로 만들어 주는 앱입니다. Windows와 macOS에서 실행됩니다.

- 건물: 브이월드 **GIS건물통합정보**를 쓰고, 빠진 건물과 높이는 **OpenStreetMap**으로 보완합니다.
- 지형: **Copernicus DEM 30m**를 자동으로 내려받습니다.
- 도로·다리·녹지·물: **OpenStreetMap**(Geofabrik 한국 데이터)을 자동으로 내려받습니다.
- 렌더: 건물과 땅은 흰색이고 녹지·물·도로에만 색이 들어갑니다. AO(앰비언트 오클루전) 합성과 카메라 배치까지 설정된 상태로 나옵니다.

## 필요한 것

1. **Blender 3.3 이상**. 4.x와 5.x에서도 동작하고, 앱이 설치된 Blender를 자동으로 찾습니다.
2. **브이월드 GIS건물통합정보** 시도별 zip. 로그인이 필요해서 직접 받아야 합니다(아래 "건물 데이터 폴더" 참고).
3. 처음 실행할 때 인터넷 연결이 필요합니다. OSM 약 300MB와 지형 타일을 받고, 이후에는 캐시를 사용합니다.

## 건물 데이터 폴더 (전국 관리)

전국 시도별 zip을 한 폴더(기본값 `~/CityModel/건물데이터`)에 모아 두고 갱신하는 방식입니다. 오른쪽 **[건물 데이터]** 탭에서 관리합니다.

- **시도 목록**: 브이월드 공개 목록(로그인 불필요)을 읽어 16개 시도의 **최신 기준일·용량**과 **내 폴더 보유 날짜**를 함께 보여 줍니다. 2026년 기준으로 광주와 전남은 "전남광주통합특별시" 하나입니다.
  - 흐린 항목: 이미 최신 파일이 있음 (선택되지 않음)
  - 검은 항목: 없거나 더 새 버전이 있음 → 받기 가능
  - 빨간 항목·★: 지금 설정한 범위에 필요한데 없음
- **받기**: **[범위에 필요한 것 받기]** 또는 항목을 고르고 **[선택 받기]**를 누르면, 기본 브라우저에서 해당 시도 파일이 바로 다운로드됩니다. 브라우저에서 브이월드에 **로그인되어 있어야** 합니다.
- **가져오기**: 받은 뒤 **[다운로드 폴더에서 가져오기]**를 누르면, 폴더에 있는 것보다 새로운 zip을 찾아 옮깁니다. **[zip 추가…]**로 직접 골라도 됩니다.
- **사용**: 시도마다 날짜가 가장 최신인 zip만 쓰고, 범위에 걸치는 시도는 자동으로 선택됩니다.
- **인덱스**: 새 zip은 처음 쓸 때 한 번 인덱스를 만듭니다. 서울은 약 2.5분 걸리고, 이후에는 범위 부분만 바로 읽습니다.
- **정리**: **[이전 버전 정리]**를 누르면 최신 외의 zip과 인덱스를 지웁니다.
- **자동 로그인은 지원하지 않습니다.** 브이월드는 정부통합 로그인(Any-ID)을 쓰기 때문에, 다운로드는 사용자의 브라우저 로그인 상태로 진행합니다.

## 카메라: 웹 지도 시점 가져오기

웹 지도에서 원하는 시점을 잡고 **주소창 URL**을 "카메라" 칸에 붙여 넣으세요. **[확인]**을 누르면 해석 결과가 표시됩니다.

| 지도 | 가져오는 정보 |
|---|---|
| 구글 어스 웹 (`earth.google.com/web/@…`) | 바라보는 지점, 거리, 방위, 기울기, 화각 (가장 정확) |
| 구글 지도 3D (`google.com/maps/@…,a,y,h,t`) | 지점, 거리, 방위, 기울기, 화각 |
| 구글 지도 2D (`…,15z` / `…,800m`) | 지점, 줌 (내려다본 시점) |
| 네이버 지도 (`map.naver.com/p?c=…`) | 지점, 줌, 기울기, 회전 |
| 카카오맵 (`urlX, urlY, urlLevel`) | 지점, 줌 (내려다본 시점) |
| 브이월드 | URL의 경위도·고도·방위·기울기 파라미터를 최대한 해석 |
| 직접 입력 | `위도,경도,거리,방위,기울기[,화각]` |

- 생성할 때 URL이 있으면 그 시점으로 카메라를 놓습니다.
- **[기존 .blend에 적용…]**을 누르면 이미 만든 파일에 카메라를 하나 더 추가하고 활성 카메라로 지정합니다. 기존 카메라는 남아 있습니다.
- 지형 과장(기본 1.6) 때문에 산이 많은 구도는 웹 지도와 조금 다를 수 있습니다. 똑같이 맞추려면 지형 과장을 1.0으로 두세요.

## 사용법

1. **범위**를 프리셋에서 고르거나 경위도로 입력합니다.
2. **건물 데이터 폴더**에 필요한 시도 zip이 있는지 확인합니다.
3. 필요하면 **카메라 URL**을 넣고, **작업 폴더**와 **프로젝트 이름**을 확인합니다.
4. **생성 시작**을 누릅니다. 서울 전체 기준으로 15~30분 걸립니다.
5. `작업폴더/프로젝트이름/프로젝트이름.blend`가 만들어집니다. Blender에서 열고 **F12**로 렌더하세요.

## 렌더 팁

- **GPU 렌더**: 환경 설정 → 시스템 → Cycles 렌더 장치에서 Metal(Mac) 또는 CUDA/OptiX(NVIDIA)를 켜세요.
- **AO 진하기**: Compositing 탭 → `AO 강도` Math 노드 값을 바꾸세요. 범위는 월드 속성 → 앰비언트 오클루전 → 거리에서 조정합니다.
- **색**: `Ground` 재질에서 녹지와 물(Mix 노드 두 개)을, `Road` 재질에서 도로를, `Clay_Building` 재질에서 건물 색을 바꿉니다.
- **현재 뷰로 렌더**: 보기 → 정렬 뷰 → 활성 카메라를 뷰에 정렬을 한 뒤 F12를 누르세요.

## 개발 / 빌드

```
pip install -r requirements.txt
python -m citymodel                        # GUI
python -m citymodel --config settings.json # GUI 없이 실행
```

배포판 빌드:

- 로컬: `pip install pyinstaller` → `pyinstaller packaging/citymodel.spec --noconfirm`
- GitHub: 태그를 푸시하면(`git tag v1.0.0 && git push --tags`) Actions가 Windows / macOS(Apple Silicon, Intel)용 zip을 만들어 Release에 올립니다.

### macOS 첫 실행

서명되지 않은 앱이라 처음에는 macOS가 실행을 막을 수 있습니다. **앱을 우클릭 → 열기**로 실행하거나, 시스템 설정 → 개인정보 보호 및 보안에서 "그래도 열기"를 누르세요.

## 알려진 한계

- 높이 정보가 없는 건물(원본·OSM 모두)은 기본 7m로 들어갑니다.
- 지형은 30m 해상도이고 산 정상부가 약간 낮아집니다(건물·수목 제거 필터 때문).
- 도로는 지면 위 1.2m에 떠 있는 판입니다(지형과 겹치지 않게 하려는 처리).
- 터널은 표시하지 않습니다.
